# Markdown to HTML Converter

A Node.js application that converts Markdown files to HTML using the `marked` package.

## Features

- Converts Markdown files to HTML
- Supports standard Markdown syntax
- Provides colored console output for better user experience
- Error handling for file operations

## Installation

```bash
# Clone the repository
git clone https://github.com/DammyCodes-all/qr-generator-and-md-to-html-converter-using-node.js.git

# Navigate to project directory
cd qr-generator-and-md-to-html-converter-using-node.js

# Install dependencies
npm install
```

## Usage

1. Place your Markdown file as `sample.md` in the project root
2. Run the converter:
```bash
node convert.js
```
3. Find the output in `output.html`

## Dependencies

- marked: For Markdown parsing
- chalk: For colored console output
